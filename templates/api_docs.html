Authentication

Every route above is authenticated the same way you're authenticated right now — a session cookie. To call this API independently of a browser (a script, a cron job, anything outside the dashboard), create a personal token below and send it as "Authorization: Bearer <token>" instead. A token has exactly your own permissions, nothing more.
