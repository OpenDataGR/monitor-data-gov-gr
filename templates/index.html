HVD Compliance Check (SHACL)

Validates every HVD-tagged dataset's real DCAT-AP RDF metadata against the EU's official DCAT-AP-HVD SHACL shapes (Regulation (EU) 2023/138) — not just whether it carries the hvd_category tag.

Click Run HVD Check to validate all HVD-tagged datasets. This checks every dataset currently tagged as an EU High-Value Dataset and can take several minutes.
DCAT-AP Compliance Check (SHACL)

Validates every dataset's real DCAT-AP RDF metadata against the EU's baseline DCAT-AP structural shapes and MDR controlled-vocabulary shapes (vendored from SEMICeu's dcat-ap_shacl repo) — the same rules data.europa.eu itself checks harvested metadata against.

Click Run DCAT-AP Check to validate every dataset on the portal. This covers the full catalog (tens of thousands of datasets) and can take a long time on the first run.
GeoDCAT-AP Compliance Check (SHACL)

Validates every geospatial-tagged dataset's real DCAT-AP RDF metadata against the EU's official GeoDCAT-AP geospatial extension SHACL shapes (SEMICeu GeoDCAT-AP 3.1.0) — covers the ~12,500 datasets the portal itself classifies as geospatial (GIS layers, WMS/WFS services, etc).

Click Run GeoDCAT-AP Check to validate every geospatial-tagged dataset on the portal. This can take a long time on the first run.
EU Metadata Quality Assessment (MQA)

data.europa.eu continuously computes this FAIR+ metadata quality score for data.gov.gr's harvested catalogue — findability, accessibility, interoperability, reusability and contextuality. This is fetched from their public API and cached here, not recomputed locally.

The MQA score hasn't been fetched yet. Click Refresh Now to pull the latest score from data.europa.eu.
